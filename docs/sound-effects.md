# Sound effects wishlist

The game currently has **no audio at all** (no `Audio`/sound code anywhere in
`src/`). These are the SFX we need, grouped by where they're triggered.

## Player / combat
- Sword swing and hit
- Sword hit on enemy / flesh impact
- Sword miss (whoosh)
- Gunshot (musket for old eras, rifle for modern)
- Bow draw + arrow release, arrow whiz
- Arrow / bullet impact
- Reload / weapon switch click

## Player state
- Player hurt grunt
- Player death sting
- Damage flash tick (low-health heartbeat?)
- Footsteps (grass, sand, snow variants per battle)

## NPC / boss
- NPC gunshots (Russian soldier rifle, hunting rifle, etc.)
- NPC melee swing + hit (templar, mongol, Mamluk)
- Horse gallop + neigh (mongols, hussars)
- Boss intro stinger + voice taunt
- Boss hurt, boss death sting
- Explosion (bin Laden, Uncle Sam, manna impacts)

## Boss-ability specific
- Jesus: holy ray charge-up + fire, divine light impact, spire orb hum
- Moses: plague cloud hiss, staff strike whoosh, water-wall crash (Red Sea),
  manna impact chime
- Winged Hussar: charge trumpet, ray storm zap, horde summon horn
- Genghis Khan: tether crack, horse charge
- Joan of Arc: holy beam, lightning bolt
- Napoleon: artillery blast, bolt zap
- Caesar, Washington, Lenin…: per-boss ability sounds as those get arted

## UI / flow
- Globe map marker click, battle select confirm
- Battle briefing screen text blip
- Victory fanfare
- Death sting, quiz question appear, correct / wrong answer
- Secret jar pickup chime

## Ambient
- Battlefield ambience loops per era (wind, distant artillery, birds)
- Star-field / map ambient pad
- Rain/snow where applicable (Chosin Reservoir, Stalingrad)

## Nice-to-have
- Intro music on the title screen
- Briefing narration for the AP history blurbs
- Boss "translation scramble" glitch sound for the bilingual taunts
